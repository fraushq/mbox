# mbox - v0.45

Браузерный музыкальный плеер. Загружаешь свои треки — они хранятся локально
в IndexedDB, ничего не уходит на сервер.

## Фичи
- Эквалайзер на 10 полос
- Crossfade между треками
- Глобус с регионами (клик → случайный трек)
- Эко-режим
- Свои фоны
- Визуализатор (bars / wave / pulse)
- Поиск текста по названию
- Фон от обложки трека
- Фон переносится по медиаданным
- Акцентный цвет меняется от основного цвета обложки трека
